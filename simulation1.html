How the modes differ: Coordinated mirrors the pitched architecture — A* for routing, a priority rule (fewer steps-to-goal wins) plus a one-cell sidestep for local conflict resolution, and nearest-idle-robot bidding for task assignment (a simplified Contract Net). Stop-and-wait keeps the same routing but removes all negotiation: a robot facing an occupied cell just halts, with a last-resort random shuffle after a long stall to avoid a true deadlock. Both modes guarantee zero collisions by construction — the metric that differs is how long the fleet takes to clear the same task list.
